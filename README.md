# ปาร์ตี้วันเกิด Misfortune

เกมตอบคำถามวันเกิดวันที่ 26 ตุลาคม เปิดหน้าแรกแล้วกดเล่นได้เลย มี 4 ข้อ ตอบถูกแล้วจะไปข้อถัดไป และหน้าสุดท้ายโชว์เลข 34 กลางจอ

โปรเจกต์นี้เป็น Next.js เพื่อเอาขึ้น Vercel ได้ตรงๆ ไม่ต้องตั้งค่าเพิ่ม

## เล่นยังไง

- ข้อ 1 ถามว่า Misfortune เป็นเคะหรือเมะ กดได้เฉพาะ **เมะ** ปุ่มเคะจะวิ่งหนีเมื่อเอาเมาส์ไปชี้ คลิก หรือแตะด้วยนิ้วบนมือถือ
- ข้อ 2, 3 และ 4 มี 4 ตัวเลือก ตัวที่ถูกคือ **ข้อ 4** เท่านั้น ข้อความยังเป็นตัวอยู่ง่ายๆ แก้ได้ใน `src/lib/questions.ts`
- ตอบครบแล้วจะไปที่หน้า `/finale`

## รันในเครื่อง

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000)

## ขึ้น Vercel

1. สร้าง repo แล้ว push โค้ดขึ้น GitHub
2. ใน Vercel กด Add New Project แล้วเลือก repo นี้
3. Framework เป็น Next.js อยู่แล้ว ไม่มี environment variable
4. กด Deploy

หรือใช้ CLI จากโฟลเดอร์โปรเจกต์:

```bash
npx vercel
```
